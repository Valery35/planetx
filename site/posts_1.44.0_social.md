# PlanetX 1.44.0 - тексты для площадок

## RU - ВК, Facebook

PlanetX 1.44.0 для QGIS. Выпуск внутренний. Все строки каталога «Добавить данные» устроены теперь одинаково. Каждая строка сама описывает название, источник, превью, шкалу, опрос щелчком и подпись источника. Окно глобуса и строка «Поиск» берут эти сведения из общего списка строк. Новые данные добавляются в модуль без правки окна глобуса, так следующие выпуски выходят быстрее. Работа строк не изменилась. Если что-то перестало работать после обновления, напишите нам.

Выпуск - https://github.com/Valery35/planetx/releases/tag/v1.44.0

## EN - LinkedIn, Mastodon

PlanetX 1.44.0 for QGIS. An internal release. Every row of the Add data catalogue is now built the same way. Each row describes its own name, source, preview, legend, click query and credit, and the globe window and the Search line read them from one shared list. New data can be added to the plugin without touching the globe window, so the next releases come faster. The rows work as before. If something stopped working after the update, please let us know.

https://github.com/Valery35/planetx/releases/tag/v1.44.0
