# PlanetX 1.0 - объявление

## Telegram

PlanetX 1.0 - трёхмерный глобус для QGIS.

Что нового:

🌋 Исторические землетрясения на разрезе. Окно «Разрез» показывает очаги каталога ISC-GEM с 1904 года, пока включена их строка. Очаги ложатся на свою глубину и рисуют погружающуюся плиту. Шкала времени отбирает их по годам, как на глобусе.

📋 Копия вида одним щелчком. Значок кладёт вид в буфер обмена - глобус со шкалами, надписями и подписью источников, без инструментов. Картинку можно сразу вставить в письмо или чат.

🌐 Перелёт через линию перемены дат. Путь или многоугольник, который пересекает 180-й меридиан, теперь открывается на своём месте, а не на другой стороне Земли.

Плагин бесплатный, ставится из каталога QGIS по слову PlanetX. Работает в QGIS 3.36 и новее и в QGIS 4.
