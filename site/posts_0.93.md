# PlanetX 0.93 - объявление

## Telegram

PlanetX 0.93 - трёхмерный глобус для QGIS.

Что нового после 0.92:

📈 Ряд по датам в окне «Космоснимки». Кнопка «Ряд по датам…» строит график NDVI, NDWI, NBR, снега или температуры поверхности участка по всем найденным сценам Sentinel-2, Landsat или MODIS. Точка - медиана участка без облаков на дату, отрезок - разброс внутри участка. Щелчок по точке выбирает сцену, ряд сохраняется в таблицу CSV.

Так видно, как меняется участок за сезон или за годы - зелень поля, снег, гари, нагрев города летом.

Плагин бесплатный, ставится из каталога QGIS по слову PlanetX. Работает в QGIS 3.36 и новее и в QGIS 4.

Страница: https://www.informpp.ru/главная-страница/qgis-planetx
Выпуск 0.93.0: https://github.com/Valery35/planetx/releases/tag/v0.93.0

## Выпуск на GitHub

Кнопка «Ряд по датам…» окна «Космоснимки» строит график индекса или температуры поверхности участка по всем сценам списка. Точка - медиана участка без облаков на дату, отрезок - разброс внутри участка. Щелчок по точке выбирает сцену в списке, ряд записывается в таблицу CSV.

The Time series button of the Satellite imagery window charts an index or the surface temperature of the area over all scenes of the list - the median without clouds on each date with the spread inside the area. A click on a point selects the scene, the series can be written to a CSV table.

Руководство: PlanetX.pdf, PlanetX_en.pdf.
