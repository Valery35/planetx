# PlanetX 0.86 - объявление

## Telegram

PlanetX 0.86 - трёхмерный глобус для QGIS.

Что нового после 0.83:

🖥 Во весь экран - значок на панели и F11. На экране только глобус с органами навигации, шкалой времени и туром, Esc возвращает окно.
➡️ Поток по пути - флажок окна свойств пути пускает по линии бегущие штрихи. Демо «Поток грузов, схема» - Березники - Усть-Луга, порт Восточный и Роттердам.
🔤 Подписи остановок тура - на остановке внизу кадра крупно стоят название и описание метки, они попадают и в запись тура.
🧱 «Объёмом по отметкам Z» - слой с Z ложится на свои отметки, например вертикальный «3D-забор» разреза из Isoliner3D. Под прозрачной землёй рамка модели светлая.
🌍 Геоид - ползунок масштаба, разрез Земли идёт по «измятой» поверхности.
🧲 След магнитного полюса идёт от левого бегунка шкалы времени.
🌫 Строка «Атмосфера» убирает небо, гало и дымку.

Плагин бесплатный, ставится из каталога QGIS по слову PlanetX. Работает в QGIS 3.36 и новее и в QGIS 4.
