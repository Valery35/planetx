## RU - форум OSM, Facebook

PlanetX 1.42 для QGIS - подписи на глобусе издалека и общий формат сцен.

Названия на глобусе издалека мельче - до 300 км кегль прежний, к 6000 км 70 %, надписей в кадре столько же. Сцена хранит ключ подложки, PlanetX Lite и rustPlanetX открывают сцену модуля с той же подложкой. Сцена со своими картинками значков сохраняется вместе с картинками. На странице модуля - раздел «Видео».

Выпуск и руководство - https://github.com/Valery35/planetx/releases/tag/v1.42.0

## EN - OSM forum, OSGeo, LinkedIn

PlanetX 1.42 for QGIS - smaller labels from afar and a shared scene format.

Place names on the globe get smaller from afar - full size up to 300 km, 70 percent at 6000 km, with as many labels in the frame as before. A scene keeps the base map key, so PlanetX Lite and rustPlanetX open a plugin scene with the same base map. A scene with own point icon pictures is saved together with the pictures. The plugin page now has a Video section.

Release and manual - https://github.com/Valery35/planetx/releases/tag/v1.42.0
Plugin - https://plugins.qgis.org/plugins/planetx/

## Reddit r/QGIS (публикует автор, редактор в режиме Markdown)

Заголовок: PlanetX 1.42 - smaller globe labels from afar and a scene format shared with PlanetX Lite

PlanetX is a free (GPL) 3D globe plugin for QGIS 3.36+ and QGIS 4. Version 1.42:

- **Labels from afar** - place names shrink smoothly from 300 km up, to 70 percent at 6000 km, and the frame keeps as many labels as before
- **Scene base map key** - a `.planetx` scene keeps the base map key, so PlanetX Lite and rustPlanetX open it with the same base map
- **Icon pictures in scenes** - a scene with own point icon pictures is saved together with the pictures
- **Video** - the plugin page now has short videos - Finnish trains, a cockpit flight to the Matterhorn, haul trucks in an open pit, animated wind turbines

- Plugin: https://plugins.qgis.org/plugins/planetx/
- Release and manual: https://github.com/Valery35/planetx/releases/tag/v1.42.0
