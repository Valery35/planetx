# PlanetX 0.89 - объявление

## Telegram

PlanetX 0.89 - трёхмерный глобус для QGIS.

Что нового:

🧲 Глобальная геофизика в категории «Недра» каталога - аномалии силы тяжести по модели XGM2019e, возраст океанического дна, тепловой поток, скорости литосферных плит стрелками, вулканы голоцена и линии магнитного склонения с 1590 года. Щелчок по глобусу показывает значение в точке.
🌋 Томография мантии на разрезе Земли - пункт «Томография мантии» в меню «⋯» строки «Разрез Земли». Горячие медленные области мантии красные, холодные погрузившиеся плиты синие.
🧭 Магнитное поле до 1900 года считается по модели gufm1.
🖱 Левая кнопка с Ctrl сдвигает вид вдоль экрана без поворота Земли - часть разреза у края окна встаёт в середину под тем же углом. Взгляд по сторонам теперь с Ctrl и Shift.
💾 Модель коры CRUST1.0 после первой загрузки хранится в профиле QGIS. Если сайт авторов не отвечает, архив можно положить туда вручную, путь описан в руководстве.

Плагин бесплатный, ставится из каталога QGIS по слову PlanetX. Работает в QGIS 3.36 и новее и в QGIS 4.

Страница: https://www.informpp.ru/главная-страница/qgis-planetx
Выпуск 0.89.0: https://github.com/Valery35/planetx/releases/tag/v0.89.0

## Ответ Ивану в обсуждении

Иван, оба пункта вошли в 0.89.0. Левая кнопка с Ctrl сдвигает вид вдоль экрана без поворота Земли, угол зрения сохраняется. Взгляд по сторонам переехал на Ctrl+Shift. После сдвига вбок север может оказаться не вверху, клавиша N его возвращает. Модель коры, однажды скачанная, хранится в папке PlanetX профиля QGIS и дальше берётся оттуда. Вручную - скачать https://igppweb.ucsd.edu/~gabi/crust1/crust1.0.tar.gz и положить под тем же именем в папку PlanetX профиля. Папку профиля открывает меню «Установки» - «Профили пользователя» - «Открыть папку активного профиля». Потом выключить и включить строку «Разрез Земли».

## Выпуск на GitHub

Новые строки категории «Недра» каталога - аномалии силы тяжести по модели XGM2019e, возраст океанического дна, тепловой поток по базе IHFC 2024, скорости плит по модели NNR-MORVEL56, вулканы голоцена по списку Global Volcanism Program и линии магнитного склонения с 1590 года. Магнитное поле до 1900 года считается по модели gufm1.

Пункт «Томография мантии» меню «⋯» строки «Разрез Земли» раскрашивает мантию на гранях по модели SEISGLOB2.

Левая кнопка с Ctrl сдвигает вид вдоль экрана без поворота Земли. Взгляд по сторонам - левая кнопка с Ctrl и Shift.

Скачанная модель коры CRUST1.0 хранится в профиле QGIS. Если сайт авторов не отвечает, архив можно положить туда вручную.

New rows of the Inside the Earth category - XGM2019e gravity anomalies, ocean floor age, IHFC 2024 heat flow, NNR-MORVEL56 plate motion, Holocene volcanoes of the Global Volcanism Program and magnetic declination lines since 1590. The magnetic field before 1900 is computed with gufm1. The Mantle tomography item of the Earth cutaway colours the mantle after SEISGLOB2. Ctrl with the left button moves the view along the screen, looking around moved to Ctrl and Shift. The downloaded CRUST1.0 crust model is kept in the QGIS profile and can be put there by hand.

Руководство: PlanetX.pdf, PlanetX_en.pdf.
