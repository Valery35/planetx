# Проверка текстов

Тексты проверяют два файла.

- `tools/measure.py` - измеритель линейки: ритм, длина предложений,
  общие стоп-слова, тире, точка с запятой, двоеточие, имя файла.
- `tools/check_texts.py` - своё модуля. Он собирает тексты (markdown
  и подсказки setHelp), отдаёт их `measure.py` вызовом его функций,
  ищет стоп-слова модуля сверх общих («схват», «прямо») и «число»
  вместо «количества», выбирает полосу ритма по виду текста.

## Полоса ритма по виду текста

Требования к текстам и таблица полос - свод линейки
`C:\Dev\workplace\TEXTS.md`. Здесь только то, какой файл модуля к
какому виду текста свода отнесён. Правило - таблица `BANDS` в
`check_texts.py`, первое подходящее по пути. Ключ `--band` задаёт одну
полосу всему прогону.

| Вид текста по своду | Файлы модуля | Полоса measure.py |
|---|---|---|
| Заметка выпуска, пост, объявление | `CHANGELOG.md`, `site/posts_*.md` | letter |
| Запись ленты, подписи, перечни | `doc/PLAN_*.md`, `bot/DEPLOY.md` | register |
| Руководство, концепция, разбор | `README*.md`, `doc/MANUAL*.md`, `AGENTS.md`, прочее | note |

Страницы сайта `site/pages/*.html` собирает `tools/build_pages.py`,
markdown у них нет, проверкой они не меряются. Подсказки setHelp идут без
полосы - в подсказке от одного до пяти предложений, ритм на таком отрезке
не меряется, проверяются пунктуация и слова.

Находки ритма и длины - сигнал смотреть текст глазами. Короткая проверка
перед выпуском (`tools/release_check.py`) выводит их замечанием и выпуск
не останавливает.
