# PlanetX 0.96 - объявление

## Telegram

PlanetX 0.96 - трёхмерный глобус для QGIS.

Что нового после 0.95:

🎛 Элементы на виде в одном стиле. Панель значков, шкала времени, панель тура, шкалы слоёв и значок загрузки - тёмная полупрозрачная плашка со светлыми значками одного набора. Включённое отмечено синим, у кнопок с меню есть белая стрелка.

🧭 Точка в середине кольца навигации возвращает отвесный взгляд на Землю. Нижний джойстик издалека двигает вид медленнее и не уносит камеру на полюс.

✨ Новые тайлы проявляются плавно, из размытого вида в резкий.

📝 Окно свойств метки разбито на группы сверху вниз - оформление, высота, время и видимость, вид метки.

Плагин бесплатный, ставится из каталога QGIS по слову PlanetX. Работает в QGIS 3.36 и новее и в QGIS 4.

Страница: https://www.informpp.ru/главная-страница/qgis-planetx
Выпуск 0.96.0: https://github.com/Valery35/planetx/releases/tag/v0.96.0

## Выпуск на GitHub

Панель значков, шкала времени, панель тура, ползунок палеогеографии, шторка, шкалы слоёв и значок загрузки выглядят одинаково - тёмная полупрозрачная плашка и светлые значки одного набора, включённое синим, у кнопок с меню белая стрелка. Точка в середине кольца навигации возвращает отвесный взгляд без крена, нижний джойстик издалека двигает вид медленнее. Новые тайлы проявляются плавнее. Окно свойств метки разбито на группы сверху вниз, пустая панель свойств справа больше не видна.

The icon bar, the time slider, the tour bar, the paleogeography slider, the swipe, the layer scales and the loading icon share one look - a dark translucent plate with light icons of one set, the active one in blue, a white arrow on buttons with a menu. The dot in the middle of the navigation ring returns the straight down view without roll, the lower joystick moves the view slower from far away. New tiles fade in more smoothly. The placemark properties window is split into groups from top to bottom, and the empty properties panel on the right no longer shows.

Руководство: PlanetX.pdf, PlanetX_en.pdf.
