# PlanetX

Трёхмерный глобус для QGIS: рельеф и подложка из открытых источников,
плавная навигация, слои текущего проекта на поверхности Земли.
Замысел: аналог Google Earth Pro внутри QGIS.

Состояние: заготовка, фаза 0 (глобус, подложка, навигация).

Разработка при поддержке ООО «Информ++» (www.informpp.ru).
