## Проверки

```
$PY -m unittest discover -s planetx/tests      ядро без QGIS
$PY tools/check_texts.py                       тексты
$PY tools/preflight.py                         готовность к каталогу
$PY tools/check_docs.py                        пары документов
$PY tools/release_check.py                     всё перед выпуском
```

`tools/release_check.py` - короткая проверка перед выпуском, см. запись
«Короткий набор шагов перед выпуском».

### Объём проверки по правке

Правило автора от 19 октября 2026 года, после третьего замечания
о лишних прогонах («тестируешь впустую больше чем пишешь и
проверяешь»). Проверка соразмерна правке. Окно глобуса разделено
на части (`ui/globe`), у каждой строки и окна свои шаги, поэтому
правка части проверяется шагами этой части, а не наборами.

| Что правилось | Что проверяется |
|---|---|
| только тексты - руководство, README, журнал, переводы | `check_docs`, `check_texts`, `test_i18n` |
| ядро `core/<модуль>.py` | его тест, перед коммитом - все тесты ядра (около минуты) |
| окно, строка, менеджер - `ui/<часть>.py`, `ui/globe/<часть>.py` | тесты ядра и шаги этой части на QGIS 4.0.3 |
| то же с различиями Qt 5 и Qt 6 (перечисления, QAction, QShortcut, sip), GDAL, сетью, потоками | плюс те же шаги на QGIS 3.36.1 |
| слой отрисовки - `render/<слой>.py` (модели, надписи, подземное, точки) | шаги этого слоя на QGIS 4.0.3 и 3.36.1 |
| общий кадр - выбор тайлов `core/lod.py`, `core/tiling.py`, шейдер тайла, `render/gpu.py`, цикл кадра `render/view.py`, загрузчик `net/loader.py`, хранилище высот, `qt_compat.py` | набор GLOBE на QGIS 4.0.3 и 3.36.1 |
| выпуск | ничего сверх уже пройденного для вошедшего: тесты ядра, `check_docs`, `check_texts`, `build_zip` с `preflight` |

- Шаг, который прошёл, второй раз не запускается, пока не менялся код,
  который он проверяет.
- Новая возможность получает свои шаги и сторожа, разобранная ошибка -
  сторожа, который краснеет на прежнем коде. Это часть работы, а не
  лишний прогон.
- Кадр глазами смотрится только у нового видимого результата.
- Полный прогон всех шагов - только по слову автора.

Проверки внутри QGIS лежат в `tools/qgis_*.py` и запускаются через мост.
Состав описан в `doc/PLAN_PHASE0.md`.

Правила кода стерегут тесты `tests/test_hygiene.py`. Каждый сторож
проверяется там же на образце с нарушением. Проверку текстов стерегут
тесты `tests/test_check_texts.py`.

В Python из QGIS нет pyflakes и pycodestyle. Ширину строки проверяет
`test_hygiene`, анализ pyflakes в `preflight.py` пропускается
с замечанием.

`preflight.py` до первого выпуска выдаёт ошибку про отсутствующий значок.
Это ожидаемо, значок появляется к выпуску.
