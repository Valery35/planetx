# Подземный режим PlanetX

Раздел руководства о режиме, скрытом до своего выпуска. Английская
версия лежит в `SUBSURFACE.en.md`.

## Подземный режим

Значок «Подземный режим» на панели значков открывает окно с тем же
названием. Режим показывает под поверхностью скважины, кровли пластов,
стенки разрезов и вырез блока.

### Данные

Данные - таблицы в той же разметке, что у Isoliner.

| Таблица | Поля | Что задаёт |
|---|---|---|
| collar | hole_id, z, eoh, геометрия - точка | Устье скважины, отметка устья, глубина забоя по стволу |
| interval | hole_id, from, to, code | Интервалы по стволу, вниз положительные, code - пласт или литология |
| survey | hole_id, depth, azimuth, dip или zenith | Инклинометрия. Без неё скважина вертикальная |
| beds | code, ord, color, surface | Порядок пластов сверху вниз, цвет «#rrggbb», файл растра кровли |
| sections | геометрия - линия | Линии разрезов |
| cut | геометрия - многоугольник | Вырез блока |

Поля ищутся и по другим принятым именам, например bhid, elev, td,
from_m, to_m, litho. Угол dip с отрицательными значениями считается
от горизонта, -90 - вниз отвесно. Кровля пласта - растр отметок
в метрах в любой системе координат, его читает GDAL.

Источник выбирается в окне. «Файл GeoPackage» берёт таблицы с этими
именами из одного файла, растры кровель - по полю surface таблицы
beds, путь отсчитывается от папки файла. «Слои проекта» берёт таблицы
из слоёв текущего проекта, кровли - из отмеченных в списке растров,
код пласта у кровли - имя слоя.

### Показ

Кнопка «Построить» читает данные, загружает высоты рельефа под
моделью и строит её.

- Ствол скважины идёт по инклинометрии методом минимальной кривизны.
  Интервалы окрашены цветом своего пласта, над устьем - номер
  скважины.
- Кровля пласта - поверхность цвета пласта.
- Разрез - стенки вдоль линии от рельефа до низа модели, между
  кровлями - пласты своих цветов.
- Низ модели - забой самой глубокой скважины, без скважин - на 20 м
  ниже самой глубокой кровли.

Глубина растягивается масштабом рельефа, как и поверхность. При
выключенном рельефе отметки отсчитываются от поверхности.

Ползунок «Непрозрачность поверхности» делает рельеф в рамке модели
прозрачным, сквозь него видны скважины и кровли. Вне рамки поверхность
остаётся непрозрачной. Флажок «Вырез блока» убирает поверхность
и кровли внутри многоугольника выреза. По краю выреза встают стенки
с пластами, на дне лежит плоскость низа модели. Флажок «Камера под
землёй» позволяет опустить камеру ниже рельефа до низа модели. В рамке
модели камера тогда ходит по её низу. Кнопка «Убрать» снимает подземное
с глобуса. Настройки окна хранятся в проекте.

Демо «Пермские отложения» в значке «Демо» открывает синтетический
участок у Березников, на Верхнекамском месторождении. На нём 24 скважины, 9 кровель пластов Верхнекамского
разреза, два разреза и вырез северо-восточной четверти. Данные
выдуманы для примера, это не съёмка.
